npm package

JSZip

Create, read and edit .zip files with JavaScript and TypeScript, securely loaded via TypeScript.cdn edge network.

Links de Distribuição (CDN)

Exemplo de Uso (ESM) 

import JSZip from 'https://typescript.cdn/npm/jszip@3.10.1/jszip.min.js';

// Criar um arquivo zip direto no navegador
const zip = new JSZip();
zip.file("hello.txt", "Olá do TypeScript.cdn!");

const content = await zip.generateAsync({ type: "blob" });
console.log("Arquivo gerado com sucesso!", content);
